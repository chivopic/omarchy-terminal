# Chiterm 使用手册

[English](USER_GUIDE.md) · [返回 README](../README.zh-CN.md)

## 标签页和面板

点击标题栏的 **+** 按钮或菜单中的 **New Tab** 新建标签。点击面板可切换焦点。通过标题栏菜单或下方快捷键，将当前面板左右或上下分屏。拖动分隔线可调整大小，拖动标签标题可重新排序。

如果 shell 通过 OSC 7 报告本地工作目录，新标签和分屏会沿用当前面板的目录；否则从主目录启动。远程目录不会作为本地路径使用。

最大化面板会暂时隐藏同一标签里的其他面板，切换面板焦点或再次使用快捷键即可恢复。隐藏的 shell 会继续运行。

## 终端配色

从标题栏菜单选择 **Theme**，可切换四种 Chiterm 原创配色：深色的 **Midnight Fern**、**Harbor Dusk**，以及浅色的 **Paper Bloom**、**Sage Ledger**。这些配色不是对第三方主题包的复刻。更改会立即应用到所有打开的面板，包括隐藏面板；新面板也会沿用当前配色。设置保存在 `$XDG_CONFIG_HOME/chiterm/config.json`，未设置该变量时使用 `~/.config/chiterm/config.json`。配置无效时会在启动时回退到默认配色；保存失败时会显示提示。配色只影响终端颜色，GTK 标题栏仍跟随桌面主题。

## 搜索

按 **Ctrl+Shift+F** 搜索当前面板的滚动回看。搜索会循环查找，并在输入时更新。可在搜索栏选择：

- **智能大小写：**全小写查询忽略大小写；查询中出现大写字母时区分大小写。
- **区分大小写**或**忽略大小写：**固定搜索的大小写规则。
- **正则表达式：**将查询作为 PCRE2 表达式。表达式无效时，搜索栏会显示错误。

没有匹配项时，搜索栏会显示 `No matches`。搜索只作用于当前聚焦面板。

## 链接和剪贴板

按住 Ctrl 单击 HTTP(S) 链接，可在默认浏览器中打开。普通单击仍可供终端程序使用。复制和粘贴使用桌面剪贴板。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+T | 新建标签 |
| Ctrl+Shift+D | 左右分屏 |
| Ctrl+Shift+E | 上下分屏 |
| Ctrl+Shift+W | 关闭当前面板或标签 |
| Ctrl+Shift+C / V | 复制 / 粘贴 |
| Ctrl+Shift+F | 搜索当前面板 |
| Ctrl+Shift+G / Ctrl+Shift+Alt+G | 下一个 / 上一个结果 |
| 搜索框中的 Enter / Shift+Enter | 下一个 / 上一个结果 |
| 搜索框中的 F3 / Shift+F3 | 下一个 / 上一个结果 |
| 搜索框中的 Escape | 关闭搜索 |
| Ctrl+Shift+] / Ctrl+Shift+[ | 下一个 / 上一个面板 |
| Ctrl+Shift+Enter | 最大化 / 恢复当前面板 |
| Ctrl+Page Down / Page Up | 下一个 / 上一个标签 |
| Ctrl++ 或 Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 重置字体 |

## 限制和排障

关闭面板或窗口前会要求确认。确认后会结束对应的 shell 和前台进程。Chiterm 退出后不会恢复标签或面板，暂不支持配置档和 Omarchy 配色自动同步。

- **提示 `No module named gi` 或找不到 GTK/VTE 命名空间：**安装系统软件包，并使用 `/usr/bin/python`，不要使用缺少这些绑定的虚拟环境。
- **窗口没有打开：**从 Wayland 或 X11 桌面会话启动，并检查启动终端输出的错误。
- **新面板从主目录启动：**配置 shell 通过 OSC 7 报告本地工作目录。
